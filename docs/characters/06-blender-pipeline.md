# Пайплайн моделей: Blender → Unity

Модели делаем **сами в Blender**. Установлен **Blender 5.3.0**
(`C:\Program Files (x86)\Steam\steamapps\common\Blender\blender.exe`).

Документ описывает **стандарт**, чтобы модели, сделанные разными людьми
(и разными агентами), не разваливались при сборке.

## 1. Общие правила

- Работаем **в метрах**, масштаб 1.0 = 1 м. Blender unit scale = 1.0.
- **Y-up → Unity конвертирует сама**, но ось «вперёд» у персонажа = `+Y` в Blender.
  Иначе модели будут смотреть в стену.
- Origin модели — **на полу между ступнями**, а не в центре массы.
- Применяем трансформации (`Ctrl+A → All Transforms`) перед экспортом. Всегда.
- Формат: **.fbx** (не .blend через импорт — .blend в Unity тянет лишнее).
  Пресет экспорта ниже.

## 2. Полигонаж (очень низкий — стиль этого требует)

Манга-стилизация не прощает лишней геометрии: чем меньше полигонов, тем
чище силуэт и тем лучше работает контур через hull-шейдер.

| Объект | Треугольников | Комментарий |
|---|---|---|
| NPC (массовка) | **800–1500** | тело, голова, 2 предмета |
| NPC (уникальный) | **1500–2500** | чуть детальнее, портрет всё равно 2D |
| Руки ГГ (FPS) | **2500–4000** | главный ассет, тут можно не экономить |
| Король | **4000–6000** | босс, крупнее, но пропорции человеческие |
| Оружие | **150–400** | отдельный объект, можно отрывать |

**Не сглаживаем всё подряд.** Shade Smooth только на гранях, которые реально
скруглены; иначе hull-контур начнёт «пухнуть» на рёбрах.

## 3. Развёртка и текстуры

Нам **не нужны PBR-текстуры**. Нужны максимум три вещи:

1. **Base color** — плоская заливка. Почти всегда белая или один из серых.
2. **Маска штриховки** — ч/б текстура, по которой шейдер рисует линии в тени.
   Одна общая на весь проект, 512×512, тайлится.
3. **Маска трещин** (только для ГГ) — где светится огонь.

Поэтому: **на всю массовку можно сделать 2–3 общих атласа**. Уникальные NPC
получают по одной текстуре 512×512.

Правило: **не рисовать детали, которые не видно с 2 метров**. Игрок не будет
рассматривать пряжку на поясе.

## 4. Риг и скелет

Единый скелет-стандарт для всех людей — чтобы анимации переиспользовались:

```
Root
└─ Hips
   ├─ Spine → Spine1 → Neck → Head
   ├─ Shoulder.L → Arm.L → Forearm.L → Hand.L
   └─ Shoulder.R → Arm.R → Forearm.R → Hand.R
   ├─ Thigh.L → Shin.L → Foot.L
   └─ Thigh.R → Shin.R → Foot.R
```

**Ограничение по костям: 20–24 на персонажа.** Больше — не нужно и вредит
Unity-скому скинингу при массовке.

- Голова — **отдельная кость**, потому что голова NPC крутится к игроку
  (это делает 90% работы по «живости»).
- Пальцы — **только у рук ГГ**. У NPC пальцев нет, это кисть-варежка.

## 5. Анимации

Все клипы — **in-place** (без смещения корня). Движение добавляет контроллер.

| Клип | FPS | Заметки |
|---|---|---|
| `idle` | 30 | должен читаться в статике |
| `walk` | 24 | шаркающая, не героическая |
| `run` | 24 | с задыханием |
| `hit` | 24 | быстрый, 8–10 кадров |
| `death` | 24 | **важно**: оседает, не падает |
| `attack` | 24 | замах короткий |

`death` — общий для всех людей, это осознанная экономия. Разница в панели,
а не в анимации.

## 6. Пресет экспорта FBX

```
Forward:      -Z Forward
Up:            Y Up
Scale:        1.0
Apply Scale:  ✔ (Apply Transform)
Armature:     ✔ Export Deform Bones only
Animation:    ✔ (все клипы в одном FBX, через NLA)
Bake Anim:    ✔
Leaf Bones:   ✘
```

Проверка после экспорта: импортировать в Unity, поставить на плоскость,
посмотреть — модель стоит **на полу**, смотрит **вперёд**, высота **1.75 м**.

## 7. Конвенция имён (иначе будет хаос)

```
CHR_Peasant_A          — крестьянин, вариант A
CHR_Peasant_Rag        — крестьянин с мокрой тряпкой
CHR_Guard_A            — стража
CHR_Guard_Bucket       — стража с ведром
CHR_Archer             — лучник
CHR_King               — король
CHR_Hands_Player       — руки ГГ (FPS)
WPN_Club / WPN_Spear / WPN_Bow / WPN_Scepter
PROP_Bread             — хлеб
```

Суффиксы: `_A`, `_B` — варианты; `_LOD1` — упрощённая версия.

Всё в папках:
```
Assets/Art/Characters/<Name>/
    Models/  Textures/  Animations/  Materials/
```

## 8. Что я могу автоматизировать

Blender 5.3 поддерживает запуск скриптов из консоли:

```
blender.exe --background --python script.py
```

Это значит, что **базовые вещи я могу генерировать скриптом**, без ручной
работы: болванки пропорций, серые боксы для тестов, риг по стандартному
скелету, экспорт FBX пачкой. Так мы получаем «серый прототип» быстро,
а художник потом заменяет геометрию, не трогая риг и анимации.

**Предлагаю так и начать**: я генерю скриптом болванки всех типов врагов
с правильными пропорциями и силуэтами → в Unity сразу играбельно → потом
красим и детализируем.

## 9. Открытые вопросы

1. **Кто моделлит** — я скриптом болванки, человек руками, или оба?
2. Есть ли **опыт в Blender** у кого-то из команды, или всё через агента?
3. **Стиль головы**: шар/куб/плоская пластина? Плоская пластина дешевле
   и лучше под мангу, но требует аккуратной стыковки с шеей.
