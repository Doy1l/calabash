## Четыре правила

1. **Цвет — информация, не декор.** Оранжевый = огонь/ГГ, красный = смерть,
   голубой = вода (повышенный урон). Больше цветов нет.
2. **Лицо NPC в бою — простая декаль. Лицо в смерти — детальная панель.**
   Вся детализация тратится в момент смерти, не раньше.
3. **Руки ГГ — его портрет.** Стадия тления читается по рукам, не по HUD.
4. **Силуэт читается в 64 px.** Не читается — переделывать.
